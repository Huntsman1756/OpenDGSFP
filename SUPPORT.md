# Support

OpenDGSFP is an open-source engineering/research project, not a hosted service and not an official regulatory support channel.

## Where to ask

Use GitHub issues for:

- reproducible software bugs;
- data-quality/source disagreements;
- bounded feature proposals;
- documentation problems.

Use the provided issue templates where possible.

For vulnerabilities or exploit details, follow `SECURITY.md` instead of posting sensitive details publicly.

## What to include

For code problems:

- exact commit/tag;
- Python/environment details where relevant;
- minimal reproduction;
- traceback/test output.

For data/identity problems:

- DGSFP key, LEI or other exact identifier;
- source systems involved;
- source/snapshot dates;
- URL/file/hash where available;
- exact assertion made by each source;
- enough context to distinguish snapshot lag from identity disagreement.

## What this project cannot provide

OpenDGSFP does not provide:

- official DGSFP/BdE/EIOPA/GLEIF support;
- legal or regulatory advice;
- confirmation that an entity is currently authorized beyond the source snapshot represented;
- production SLA or guaranteed response time;
- private consulting through public issue threads.

For current legal/regulatory status, consult the authoritative live register directly.
